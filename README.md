# Atividades de Computação Gráfica

## Executar no Google Colab

1. Acesse [Google Colab](https://colab.research.google.com/) e escolha **Arquivo > Abrir notebook > GitHub**.
2. Cole a URL deste repositório: `https://github.com/4hoshua/CG-Atividades`.
3. Abra [lista_1.ipynb](lista_1.ipynb), [lista_2.ipynb](lista_2.ipynb), [lista_3.ipynb](lista_3.ipynb) ou [lista_4.ipynb](lista_4.ipynb).
4. Se escolher a lista 1, altere `USAR_UPLOAD_COLAB = False` para `True` na célula de carregamento da questão 2. Ao executar essa célula, envie uma imagem do seu computador. A lista 2 não precisa de arquivos adicionais; a questão 4 da lista 3 e a questão 5 da lista 4 baixam o modelo Suzanne automaticamente quando necessário.
5. Selecione **Ambiente de execução > Executar tudo**. Os gráficos aparecem no notebook e as imagens geradas são salvas no ambiente do Colab.

Para manter as alterações feitas no Colab, use **Arquivo > Salvar uma cópia no Drive**.
